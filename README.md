Прототип электронного дневника (расписание, оценки, классный журнал,
домашние задания, сообщения)

## Как всё работает

Сайт полностью автономный — это один файл `index.html`. Никакого сервера и
базы данных не требуется. Данные (оценки, задания, ученики) сохраняются в
браузере (localStorage) **на каждом устройстве отдельно**.

## Публикация в интернет (GitHub Pages)

Так сайт работает на телефоне с любого места и при выключенном ПК.

1. Создайте бесплатный аккаунт: https://github.com/signup (2–3 минуты).
2. Войдите и создайте новый репозиторий: кнопка **New** (справа сверху).
   Назовите, например, `vgu-stats`. Публичный (Public).
3. После создания в репозитории нажмите **Add file → Upload files**.
4. Перетащите сюда файлы: `index.html`, `README.md` (остальные не нужны).
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages** → в разделе **Branch** выберите ветку
   `main` и папку `/ (root)` → **Save**.
7. Через 1–2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/vgu-stats/`

Всё, откройте эту ссылку на телефоне. Правки, сделанные на одном устройстве,
сохраняются только на нём (localStorage). Чтобы изменения были везде
одинаковыми, нужен сервер с общей базой — это отдельный шаг.
