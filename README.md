# ВГУstats — школьный портал с локальным бэкендом

Прототип дневника в духе «Дневник.ру»: расписание, оценки, классный журнал,
домашние задания и сообщения. Сервер написан на чистом Python (без установки
зависимостей), данные хранятся в файле `data.json`.

## Что внутри

| Файл         | Назначение                                        |
|--------------|---------------------------------------------------|
| `index.html` | Страница портала (роли: ученик / родитель / учитель) |
| `server.py`  | Локальный HTTP-сервер: отдаёт сайт + REST API        |
| `data.json`  | Данные (ученики, расписание, оценки, журнал, д/з, сообщения) |
| `start.bat`  | Запуск сервера двойным кликом (Windows)              |

## Запуск на этом компьютере

Проще всего — двойной клик по **`start.bat`**. Откроется консоль, затем браузер с сайтом `http://localhost:8555/`.

Или вручную в терминале (из папки `vgu-stats`):

```
python server.py
```

Сайт станет доступен по адресу `http://localhost:8555/`.
Остановить сервер — `Ctrl+C` (или закрыть окно консоли).

> Нужен Python 3. Других установок не требуется.

## Открыть с телефона (в той же Wi-Fi сети)

1. Убедитесь, что компьютер и телефон в одной Wi-Fi сети.
2. Запустите сервер на компьютере (`start.bat`).
3. В консоли появится адрес вида `http://192.168.1.X:8555/`.
4. Откройте этот адрес в браузере телефона.

Если телефон не подключается — разрешите доступ для Python в брандмауэре Windows
при первом запуске (окно брандмауэра → «Доступ» для частных сетей).

## API

| Метод | Адрес        | Описание                          |
|-------|--------------|-----------------------------------|
| GET   | `/api/data`  | Получить все данные (JSON)        |
| POST  | `/api/data`  | Сохранить данные (тело — JSON)    |

Страница сама грузит данные с `/api/data` и сохраняет их при добавлении
домашних заданий и сообщений. Если `index.html` открыт напрямую как файл
(без сервера) — работает на встроенных демо-данных без сохранения.

## Замена данных

Отредактируйте `data.json` (после изменения перезапустите сервер).
Либо отредактируйте/добавьте записи через интерфейс: раздел «Домашние задания»
у учителя и «Сообщения» сохраняют изменения на сервер.

## Настройки

Порт по умолчанию — `8555`. Изменить: переменная окружения `VGUSTATS_PORT`
или строка `PORT` в `server.py`.
